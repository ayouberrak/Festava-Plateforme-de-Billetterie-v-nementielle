# 🌐 Projet Festava Blog

## 📘 Contexte du projet
L’entreprise **Festava** a reçu une offre de projet pour créer un **site web sous forme de blog**.  
Le site doit être développé uniquement en **HTML** et **CSS**.

---

## ⚙️ Fonctionnalités à réaliser

### 🗂️ Planification et Organisation
- Créer un **tableau Trello** pour organiser les tâches (maquettes, développement, tests).
- Estimer le **temps de travail** pour chaque tâche.

### 🎨 Conception des Maquettes
- Créer des **maquettes simples** pour les pages **Home**, **Events** et **Blog**.
- Assurer une **navigation claire** entre les pages à l’aide d’un menu.

### 💻 Développement
- Utiliser des **balises HTML sémantiques**.
- Utiliser **CSS Grid** pour organiser les sections.
- Respecter le **design des maquettes**.

### 📄 Pages du site
- Créer une structure multi-pages :
  - `Home.html`
  - `Events.html`
  - `Blog.html`
- Lier les pages entre elles via un **menu de navigation**.

### 🌐 Hébergement
- Héberger le projet sur **GitHub Pages**, **Vercel**, ou un autre service gratuit.
- Fournir le **lien du site hébergé** et le **lien du dépôt GitHub**.

### 📑 Documentation
- Ajouter un fichier **README.md** expliquant :
  - La structure du projet
  - Les fichiers principaux
  - Les liens utiles

---

## 🧩 Modalités d’évaluation
- **10 min** : présentation du site et démonstration  
- **5 min** : revue de code et questions techniques  
- **5 min** : mise en situation professionnelle
